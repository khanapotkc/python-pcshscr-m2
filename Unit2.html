การเขียนโปรแกรมแบบทางเลือก

1) ตัวดำเนินการเปรียบเทียบและตรรกะ

ก่อนที่จะสร้างเงื่อนไขได้ เราต้องรู้จักเครื่องมือที่ใช้ในการเปรียบเทียบค่าสองค่า หรือรวมเงื่อนไขเข้าด้วยกัน ซึ่งผลลัพธ์ที่ได้จะเป็นจริง (True) หรือ เท็จ (False) เสมอ

ข้อแตกต่างจากวิชาคณิตศาสตร์

ในภาษา Python เราจะไม่ใช้สัญลักษณ์ทางคณิตศาสตร์แบบดั้งเดิม (เช่น ≠, ≤, ≥) แต่จะใช้อักขระบนคีย์บอร์ดประกอบกันแทน (เช่น !=, <=, >=)
💡 ข้อควรระวังที่สุด: การเปรียบเทียบว่า "เท่ากันหรือไม่" ต้องใช้เครื่องหมายเท่ากับสองตัว == เสมอ! เพราะเครื่องหมาย = ตัวเดียว ถูกสงวนไว้ใช้สำหรับ "กำหนดค่าให้ตัวแปร" เท่านั้น

ตัวดำเนินการเปรียบเทียบ

ตัวดำเนินการ ความหมาย รูปแบบการใช้งาน
> เป็นจริง เมื่อค่า x มากกว่า y (Greater than) x > y
< เป็นจริง เมื่อค่า x น้อยกว่า y (Less than) x < y
== เป็นจริง เมื่อค่า x เท่ากับ y (Equal to) x == y
!= เป็นจริง เมื่อค่า x ไม่เท่ากับ y (Not Equal to) x != y
>= เป็นจริง เมื่อค่า x มากกว่าหรือเท่ากับ y x >= y
<= เป็นจริง เมื่อค่า x น้อยกว่าหรือเท่ากับ y x <= y

ตัวดำเนินการตรรกะ

สัญลักษณ์ (Keyword) เงื่อนไขการเป็น True
and (และ) เป็นจริง เมื่อจริงทั้งคู่ นอกนั้นเท็จ
or (หรือ) เป็นจริง เมื่อมีจริงอย่างน้อย 1 อัน
not (ไม่) กลับค่าจาก จริงเป็นเท็จ, เท็จเป็นจริง

ลำดับความสำคัญของตัวดำเนินการ (Python Operator Precedence)

เมื่อในโปรแกรมมีเครื่องหมายหลายตัว ไพทอนจะพิจารณาทำตามลำดับความสำคัญก่อน-หลัง ดังนี้ (จากทำก่อน ไปทำทีหลังสุด):

ลำดับ ตัวดำเนินการ (Operator)
1 ( ) วงเล็บสำคัญที่สุด ทำก่อนเสมอ
2 not
3 <, <=, >, >=, !=, == กลุ่มเปรียบเทียบ
4 and
5 or

2) การเขียนโปรแกรมแบบ 1 ทางเลือก (if...else)

การใช้ if...else คือการให้โปรแกรมตัดสินใจเลือกทำงาน 2 ทาง คือ ทางที่เป็นจริง (if) และ ทางที่เป็นเท็จ (else)

โครงสร้างคำสั่ง

if เงื่อนไข:
# คำสั่งเมื่อเงื่อนไขเป็นจริง (True)
else:
# คำสั่งเมื่อเงื่อนไขเป็นเท็จ (False)

อย่าลืม! ต้องมีเครื่องหมาย Colon (:) ท้ายเงื่อนไข และต้องย่อหน้า (Indentation) คำสั่งที่อยู่ข้างในเสมอ

# โปรแกรมตรวจสอบการสอบผ่าน (คะแนนเต็ม 100)
score = int(input("กรอกคะแนนของคุณ: "))

if score >= 50:
    print("ยินดีด้วย! คุณสอบผ่าน")
else:
    print("เสียใจด้วย คุณสอบตก")
    print("พยายามใหม่ในครั้งหน้านะ")

3) การเขียนโปรแกรมแบบหลายทางเลือก (if...elif...else)

เมื่อปัญหามีเงื่อนไขมากกว่า 2 ทางเลือก (เช่น การตัดเกรด A, B, C, D, F) เราจะใช้คำสั่ง elif (ย่อมาจาก else if) มาช่วยเชื่อมเงื่อนไขเพิ่มเติมตรงกลาง

โครงสร้างการทำงาน

  1. โปรแกรมจะตรวจสอบ if แรกก่อน ถัาจริงจะทำในบล็อกนี้แล้วข้ามอันอื่นไปเลย
  2. ถ้า if เท็จ จะลงมาเช็ค elif ตัวถัดไปเรื่อยๆ
  3. ถ้าทุกเงื่อนไขเป็นเท็จหมด จะไปทำคำสั่งใน else ตัวสุดท้าย
# โปรแกรมตัดเกรด
score = 75

if score >= 80:
    print("เกรด 4")
elif score >= 70:
    print("เกรด 3")
elif score >= 60:
    print("เกรด 2")
elif score >= 50:
    print("เกรด 1")
else:
    print("เกรด 0")

4) การเขียนโปรแกรมที่มีทางเลือกแบบซ้อน (Nested if)

การซ้อนเงื่อนไข หรือ Nested if คือการใส่คำสั่ง if ซ้อนเข้าไปภายในคำสั่ง if (หรือ else) อีกชั้นหนึ่ง ใช้สำหรับกรองเงื่อนไขที่ซับซ้อนและต้องตรวจสอบเป็นลำดับขั้น

ความสำคัญของการย่อหน้า

ในการเขียนเงื่อนไขซ้อนกัน การย่อหน้า (Indentation) เป็นเรื่องสำคัญมาก ระดับการย่อหน้าจะบอกให้ไพทอนรู้ว่าคำสั่ง if ตัวไหน อยู่ภายใต้เงื่อนไขตัวไหน หากย่อหน้าผิด โปรแกรมจะทำงานผิดพลาดทันที 

# ตรวจสอบอายุและสิทธิ์เลือกตั้ง
age = int(input("ใส่อายุของคุณ: "))

if age >= 18:
    print("คุณบรรลุนิติภาวะแล้ว")
    
    # เงื่อนไขชั้นที่ 2 (ซ้อนอยู่ข้างใน)
    registered = input("ลงทะเบียนเลือกตั้งหรือยัง (y/n)? ")
    if registered == "y":
        print("คุณมีสิทธิ์ไปเลือกตั้งได้!")
    else:
        print("กรุณาไปลงทะเบียนก่อนเลือกตั้ง")
        
else:
    print("คุณยังเด็กเกินไป ไม่มีสิทธิ์เลือกตั้ง")
Interactive: จำลองตรวจสอบสิทธิ์เลือกตั้ง (Nested if)
