Unit 1

ความรู้พื้นฐานการเขียนโปรแกรมภาษาไพทอน

1) การวิเคราะห์ปัญหาและออกแบบอัลกอริทึม

ก่อนที่เราจะเขียนโค้ดได้ เราต้องเข้าใจปัญหาก่อน อัลกอริทึม (Algorithm) คือลำดับขั้นตอนการแก้ปัญหาที่เป็นตรรกะและชัดเจน เพื่อให้คอมพิวเตอร์หรือมนุษย์สามารถทำตามและได้ผลลัพธ์ที่ถูกต้อง มี 4 ขั้นตอนสำคัญ ดังนี้:

1

วิเคราะห์ปัญหา

ทำความเข้าใจว่าโจทย์ต้องการอะไร มีข้อมูลเข้า (Input) เป็นอะไร และผลลัพธ์ (Output) ที่ต้องการคืออะไร

2

ออกแบบวิธีการ

วางแผนขั้นตอนการทำงาน อาจใช้รหัสลำลอง (Pseudocode) หรือเขียนผังงาน (Flowchart) เพื่อให้เห็นภาพรวม

3

เขียนโปรแกรม

นำขั้นตอนที่ออกแบบไว้ มาแปลงเป็นโค้ดภาษาคอมพิวเตอร์ เช่น ภาษา Python

4

ทดสอบและแก้ไข

รันโปรแกรมเพื่อตรวจสอบหาข้อผิดพลาด (Bug) และทำการแก้ไขให้ทำงานได้ถูกต้องตามโจทย์

รายละเอียดเพิ่มเติม ทำแบบฝึกหัด: การวิเคราะห์ปัญหา

2) ตัวแปร ชนิดของข้อมูล และตัวดำเนินการ

ตัวแปร (Variables) & ชนิดข้อมูล

ตัวแปรเปรียบเสมือน "กล่อง" ที่ใช้เก็บข้อมูล เพื่อนำไปประมวลผลต่อ ชนิดข้อมูลหลักๆ ในไพทอนมี 4 ชนิด:

  • int
    จำนวนเต็ม (Integer) เช่น 10, -5, 0
  • float
    ทศนิยม (Float) เช่น 3.14, -0.5, 10.0
  • str
    ข้อความ (String) ต้องอยู่ในเครื่องหมาย " " หรือ ' ' เช่น "Hello", 'Python'
  • bool
    ค่าความจริง (Boolean) มีแค่ 2 ค่าคือ True (จริง) หรือ False (เท็จ) 
# การประกาศตัวแปร
name = "สมชาย"    # ข้อความ (str)
age = 14          # จำนวนเต็ม (int)
height = 165.5    # ทศนิยม (float)
is_student = True # บูลีน (bool)

ตัวดำเนินการทางคณิตศาสตร์

ใช้สำหรับคำนวณตัวเลขเหมือนวิชาคณิตศาสตร์ แต่มีสัญลักษณ์บางตัวที่ต่างออกไป

เครื่องหมาย ความหมาย ตัวอย่าง
+ บวก 5 + 2 = 7
- ลบ 5 - 2 = 3
* คูณ 5 * 2 = 10
/ หาร (ได้ทศนิยม) 5 / 2 = 2.5
// หารปัดเศษทิ้ง 5 // 2 = 2
% หารเอาเศษ (มอดุโล) 5 % 2 = 1
** ยกกำลัง 5 ** 2 = 25
รายละเอียดเพิ่มเติม: ตัวแปรและตัวดำเนินการ

3) คำสั่งพื้นฐาน Python (print & input)

print()

ใช้สำหรับ "แสดงผล" ข้อมูลออกทางหน้าจอ (Output) สามารถแสดงได้ทั้งข้อความ ตัวเลข และตัวแปร 

print("Hello, World!")
print(10 + 5)

name = "Alice"
# การนำข้อความมาต่อกับตัวแปร
print("My name is", name)
# หรือใช้ f-string (แนะนำ)
print(f"My name is {name}")
>> ผลลัพธ์หน้าจอ: Hello, World!
15
My name is Alice
My name is Alice

input()

ใช้สำหรับ "รับข้อมูล" จากแป้นพิมพ์ที่ผู้ใช้พิมพ์เข้ามา (Input) ข้อควรระวัง: ข้อมูลที่รับมาจะเป็นชนิดข้อความ (str) เสมอ หากต้องการใช้คำนวณต้องแปลงเป็นตัวเลขก่อน! 

# รับชื่อเป็นข้อความ (str)
user = input("Enter your name: ")

# รับตัวเลข ต้องครอบด้วย int() หรือ float()
age = int(input("Enter your age: "))
next_year = age + 1

print(f"Hi {user}, next year you will be {next_year}")
>> หน้าจอเมื่อรัน (ผู้ใช้พิมพ์ John และ 14): Enter your name: John
Enter your age: 14
Hi John, next year you will be 15
รายละเอียดเพิ่มเติม: คำสั่ง Print และ Input
