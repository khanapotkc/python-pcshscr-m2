Unit 3

การเขียนโปรแกรมแบบวนซ้ำ

เรียนรู้การใช้คำสั่ง while และ for เพื่อสั่งให้คอมพิวเตอร์ทำงานซ้ำๆ ตามรอบหรือเงื่อนไขที่กำหนด ช่วยลดบรรทัดโค้ดและเพิ่มประสิทธิภาพของโปรแกรม

1) การเขียนโปรแกรมแบบวนซ้ำ (while)

while loop เป็นคำสั่งวนซ้ำที่ง่ายและพื้นฐานที่สุดในภาษา Python ใช้ควบคุมโปรแกรมให้ทำงานบางอย่างซ้ำๆ ในขณะที่เงื่อนไขของลูปนั้นยังคงเป็นจริงอยู่ (True)

โครงสร้างและการทำงาน

กำหนดตัวแปรเริ่มต้น
while เงื่อนไข:
# คำสั่งที่ต้องการให้ทำซ้ำ
# อัปเดตค่าตัวแปร (เพื่อไม่ให้ลูปไม่รู้จบ)
  • ลูปจะประเมินเงื่อนไขก่อน หากเป็น True จะทำงานในลูป
  • วนกลับมาเช็คเงื่อนไขซ้ำไปเรื่อยๆ จนกว่าเงื่อนไขจะเป็น False จึงจะจบการทำงาน
ตัวอย่าง: แสดงตัวเลข 1 ถึง 4
i = 1
while i < 5:
    print(i)
    i = i + 1  # หรือ i += 1
ตัวอย่าง: การใช้ break (หยุดลูปทันที)
i = 0
while i <= 20:
    i += 2
    if i == 10:
        break  # หยุดทำงานทันทีที่ i เป็น 10
    print(i)

2) การเขียนโปรแกรมแบบวนซ้ำ (for)

for loop เป็นคำสั่งวนซ้ำที่ใช้ควบคุมการทำงาน ในจำนวนรอบที่แน่นอน มักจะใช้สำหรับการวนอ่านค่าภายในช่วงตัวเลขจากฟังก์ชัน range() หรือตัวอักษรในข้อความ

ฟังก์ชัน range()

ใน Python เรามักจะใช้ range() คู่กับ for เพื่อสร้างชุดตัวเลข

  • range(stop) เช่น range(5) จะได้ 0, 1, 2, 3, 4
  • range(start, stop) เช่น range(2, 6) จะได้ 2, 3, 4, 5
  • range(start, stop, step) เช่น range(1, 10, 2) จะได้ 1, 3, 5, 7, 9 (เพิ่มทีละ 2)
ตัวอย่าง: วนลูปตัวเลขและข้อความ
# นับเลขถอยหลัง (ลดค่าทีละ 1)
for i in range(10, 0, -1):
    print(i)

# วนลูปดึงตัวอักษรทีละตัว
for char in "mango":
    print(char)
ตัวอย่าง: Nested for loop (ลูปซ้อนลูป)
# พิมพ์รูปตารางดาว 4x4
for i in range(4):
    for j in range(4):
        print('*', end=' ')
    print() # ขึ้นบรรทัดใหม่เมื่อจบแถว

ปรับค่า Start, Stop, และ Step เพื่อดูว่าลูป for จะทำงานตามช่วงตัวเลขที่คุณกำหนดอย่างไร

for i in range(start, stop, step):
